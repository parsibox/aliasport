کلیدهای API برای Providerها

چند کلید مستقل برای هر Provider ثبت کنید. اولویت کمتر، زودتر انتخاب می‌شود؛ کلید دارای خطای Billing خودکار کنار گذاشته می‌شود.

کلیدهای واقعی باید در پنل همان Provider ایجاد شوند. AliasPort آن‌ها را به‌صورت رمزگذاری‌شده ذخیره می‌کند. خطای Billing تأییدشده باعث جابه‌جایی روی کلید بعدی می‌شود. کلید مسدودشده تا بازنشانی دستی دوباره استفاده نمی‌شود.

انتخاب Provider آماده

یک قالب انتخاب کنید تا نام، آدرس API و پروتکل به‌صورت خودکار در فرم قرار بگیرد.

قالب‌ها فقط تنظیمات عمومی را پر می‌کنند؛ کلید API باید از حساب همان سرویس وارد شود. برای اضافه‌کردن قالب جدید، فایل cmd/aliasport/web/provider-presets.json را ویرایش کنید.

انتخاب مدل Claude

شناسه مدل را انتخاب کنید تا در فیلد Alias قرار بگیرد.

گزینه «همه مدل‌ها (*)» یک قانون داخلی AliasPort است، نه مدل Anthropic. مدل‌های قدیمی ممکن است دیگر در API قابل استفاده نباشند. فهرست رسمی مدل‌ها
