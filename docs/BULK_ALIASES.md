# عملیات گروهی Model Aliases

در صفحه **Model Aliases** برای هر ردیف یک چک‌باکس وجود دارد. از چک‌باکس عنوان جدول می‌توانید همه Aliasهای موجود در جدول را یکجا انتخاب یا انتخاب آن‌ها را لغو کنید. تعداد انتخاب‌شده‌ها بالای جدول نمایش داده می‌شود.

با انتخاب حداقل یک ردیف، سه دکمه فعال می‌شوند:

- **فعال‌سازی گروهی:** تمام قوانین انتخاب‌شده فعال می‌شوند.
- **غیرفعال‌سازی گروهی:** تمام قوانین انتخاب‌شده غیرفعال می‌شوند.
- **حذف گروهی:** بعد از تأیید، تمام قوانین انتخاب‌شده از دیتابیس حذف می‌شوند و این عمل قابل بازگشت نیست.

انتخاب‌ها می‌توانند مربوط به چند Gateway باشند. عملیات فقط روی **شناسه‌هایی که تیک زده‌اید** اجرا می‌شود و سایر Gatewayها یا Aliasها را تغییر نمی‌دهد. پس از موفقیت عملیات، انتخاب‌ها پاک و جدول دوباره بارگذاری می‌شود.

## API

`POST /api/aliases/bulk` (روی پورت مدیریت برنامه، نه پورت Gateway).

```json
{
  "action": "disable",
  "ids": [
    "0123456789abcdef01234567",
    "89abcdef0123456701234567"
  ]
}
```

مقادیر قابل قبول `action`: `enable`، `disable` و `delete`.

پاسخ موفق:

```json
{"action":"disable","affected":2}
```

حداقل یک و حداکثر ۵۰۰۰ شناسه یکتای معتبر (۲۴ کاراکتر هگزادسیمال) در هر درخواست پذیرفته می‌شود. سرور **پیش از هر تغییری** وجود تمام شناسه‌ها را داخل تراکنش SQLite بررسی می‌کند. خطا در هر بخش، کل عملیات را لغو می‌کند و هیچ تغییر جزئی روی دیتابیس اعمال نمی‌شود.

برای نمونه اگر یکی از شناسه‌ها قبلاً حذف شده باشد، API کد `404` برمی‌گرداند و هیچ‌کدام از آیتم‌های انتخاب‌شده تغییر نمی‌کنند. گزینه حذف گروهی در پنل، پیش از ارسال درخواست تأیید جداگانه دارد.

## اثر بر مسیریابی مدل‌ها

غیرفعال‌کردن یک Alias دقیق، آن مدل را از فهرست `/v1/models` حذف می‌کند؛ اگر یک Alias عمومی `*` فعال باشد، می‌تواند به‌عنوان fallback کار کند. غیرفعال‌کردن `*` نیز fallback را غیرفعال می‌کند. اولویت Alias دقیق بر `*` در مدل مسیریابی بدون تغییر باقی می‌ماند.

این تغییرات با ذخیره‌سازی SQLite قبلی سازگار هستند و به مهاجرت دیتابیس نیاز ندارند.
